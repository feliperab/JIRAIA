# JIRAIA - Agile AI Platform

## Produto
Plataforma de inteligencia artificial integrada ao Jira Cloud.

## Jira
- Instancia: https://jiraia.atlassian.net
- Projeto inicial: SCRUM

## Modulos previstos
1. PI Planning Intelligence
2. Sprint Planning Assistant
3. Daily Scrum Copilot
4. Board Management
5. Agile Metrics & Forecasting

## Diretrizes
- Utilizar Kiro CLI como agente de desenvolvimento.
- Utilizar Atlassian MCP para integracao inicial.
- Utilizar Python para backend e servicos especializados.
- Nunca armazenar credenciais no Git.
- Nunca modificar tarefas sem aprovacao explicita.
- Separar observacoes reais de inferencias da IA.
- Criar testes automatizados para as integracoes.
